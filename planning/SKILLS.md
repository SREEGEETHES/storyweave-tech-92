# StoryWeave Required Skills & Tech Stack

## Programming Languages
- TypeScript (Strict, extensive types interfaces like `VideoState`)
- JavaScript
- Python (For AI API integration scripts/wrappers)

## Frontend Application Stack
- React 19
- Vite
- Tailwind CSS v4
- `@remotion/player` for real-time video composition rendering

## Backend & Cloud Infrastructure
- Node.js (API routes)
- Remotion Lambda (AWS Lambda serverless video rendering)
- Neon Serverless Postgres (Database for states, jobs, user data)
- Redis / Queue processing mechanisms (for render job orchestration)
- AWS S3 (Bucket storage and pre-signed frontend upload URLs)
- Docker / Kubernetes / Terraform for automated scalable infrastructure deployment

## AI Models & Integrations
- **Kimi K2.5**: Vibe-coding / Multimedia translation and JSON logic abstraction.
- **Qwen3-TTS**: Advanced Text-To-Speech.
- **Whisper**: Local / Fast endpoint STT captioning.
- **ACE-Step 1.5**: Background music generation.
- **Seedream 5.0 Lite**: Image Generation API.

## Design Systems & Methodologies
- Deep UX experience with multi-track editors (e.g., DesignCombo / Premiere Pro).
- Real-time dragging, timeline interactions, audio waveforms.
- White-labeled Open-Source Integration (e.g., hiding Gitroom Postiz UI within the custom branded interface).
